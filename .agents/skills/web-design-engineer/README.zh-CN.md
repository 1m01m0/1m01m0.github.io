# Web Design Engineer Skill

[English](README.md) | 中文

Web Design Engineer 是一个可复用的前端设计 Agent Skill，提供设计系统、页面布局、交互和视觉检查指引。此目录保存个人站点使用的技能副本。

## 使用

让支持 Agent Skills 的编程工具读取 [SKILL.md](SKILL.md)，并明确要设计的页面及约束。将此文件夹复制到其他项目的 `.agents/skills/` 或兼容技能目录时，同时保留 `references/`。

## 开发

主要规则位于 [SKILL.md](SKILL.md)，扩展模式位于 [references/advanced-patterns.md](references/advanced-patterns.md)。技能覆盖网页、交互原型、HTML 幻灯片、数据可视化和动画；具体设计仍需按项目已有规范调整。

## 来源与许可

原说明将设计指引归因于 [Claude Design](https://www.anthropic.com/news/claude-design-anthropic-labs) 的提示词，并声明 MIT。原集合的演示和图片未包含在此副本中。
