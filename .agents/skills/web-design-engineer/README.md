# Web Design Engineer Skill

English | [中文](README.zh-CN.md)

Web Design Engineer is a reusable front-end design skill with guidance for design systems, page layout, interactions, and visual verification. This directory contains the copy used by the portfolio project.

## Use

Ask an Agent Skills-compatible coding tool to read [SKILL.md](SKILL.md), then specify the page and its constraints. To reuse it, copy this folder, including `references/`, into another project’s `.agents/skills/` or compatible skill directory.

## Development

The main rules live in [SKILL.md](SKILL.md); extended patterns live in [references/advanced-patterns.md](references/advanced-patterns.md). The skill covers web pages, interactive prototypes, HTML slides, data visualizations, and animation. Apply the host project’s conventions when making design choices.
